# TC 팀 v2 — 모니터 출력 규칙 (SSoT)

팀장은 STEP 전환 시점마다 본 파일 Read → 모니터 블록 렌더링.

> 비용($) 표기는 전부 제거됨(2026-06-10) — cost.log 쓰기 코드 미배선으로 데이터 원천이 없어 거짓 표시 방지(팀장-1ⓑ 연장). 런어웨이 방어는 STEP 5/6/7 attempts 가드가 담당.

---

## 갱신 시점
- **STEP 전환 직후**: 이전 완료 + 다음 시작 시 1회 재출력 (권장)
- 30초 강제 주기 갱신 없음 (노이즈 방지)
- 배치 내 기능 전환 시 전체 블록 재출력

---

## 파일 출력 (PowerShell 외부 모니터용)

팀장은 모니터 블록을 **`monitor.log`에 overwrite** 저장:

```bash
MONITOR_FILE="{WORK_ROOT}/team/monitor.log"

# 모니터 블록 출력 함수 (STEP 전환마다 호출)
# ※ generate_monitor_body는 실제 정의된 함수가 아니라 의사코드 — 팀장이 아래 "출력 포맷" 섹션대로 렌더한 본문을 그 자리에 넣는다 (그대로 실행 금지)
print_monitor() {
  cat <<EOF
TC 팀 v2 에이전트 모니터  ($(date '+%H시 %M분 %S초'))
$(generate_monitor_body)
EOF
}

# 화면 + 파일 동시 출력 (파일 덮어쓰기)
print_monitor | tee "$MONITOR_FILE"
```

> `monitor.log`에는 **최신 블록 1개만** 저장 (덮어쓰기). PowerShell 외부 창 실시간 관찰 (`monitor.bat`).

---

## 상태 기호
| 기호 | 의미 |
|---|---|
| `·` | 대기 |
| `▶` | 진행중 (현재 포커스) |
| `✓` | 완료 (+소요시간/결과 요약) |
| `─ skip` | 조건부 스킵 (STEP 3 설계수정 / STEP 6 1차수정) |
| `✗` | 실패 (+에러 사유) |
| `⟲` | 재시도 중 (retry N회) |

## 실패 배치 재시도 가이드

배치 완료 블록에 실패 기능 있으면 **재실행 템플릿 1줄** 자동 출력. 복사-붙여넣기로 재시도.

```

    /tc-v2 [스프레드시트 URL] [실패기능1 URL] [실패기능2 URL]
```
